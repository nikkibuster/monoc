# Monoc

Simple monobank cli.

```
Usage: monoc <COMMAND>

Commands:
  init     Onboarding for settaping token
  balance  Get balance from main card
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
```
